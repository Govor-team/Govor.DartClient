# Govor — Dart / Flutter

Кроссплатформенный клиент мессенджера Govor на Dart и Flutter.

Исходники приложения, тесты и инструкции по запуску находятся в [`govor_mobile`](govor_mobile/README.md).

Поддерживаемые платформы: Android, Windows, Linux и web. Настройки проверок и сборок GitHub Actions находятся в [`.github/workflows/flutter.yml`](.github/workflows/flutter.yml).

```sh
cd govor_mobile
flutter pub get --enforce-lockfile
flutter run -d windows
```
