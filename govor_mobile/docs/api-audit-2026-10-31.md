## Профиль и дружба: разрешённый порядок

[Друзья и поиск](https://nas-3.gitbook.io/govor-api/api-reference/friendshipcontroller) · [Списки заявок](https://nas-3.gitbook.io/govor-api/api-reference/friendsrequestquerycontroller) · [FriendsHub](https://nas-3.gitbook.io/govor-api/signalr/friendshub-zayavki) · [Профиль](https://nas-3.gitbook.io/govor-api/api-reference/profile)

1. Получить профиль и актуальные друзья/requests/responses.
2. Для Stranger/Rejected разрешён SendRequest(userId).
3. Для исходящего Pending показать ожидание; повторный SendRequest запрещён. В сервере нет опубликованной команды отмены исходящей заявки.
4. Для входящего Pending разрешены AcceptRequest(friendshipId) и RejectRequest(friendshipId). Передавать вместо friendshipId userId нельзя.
5. После принятия сервер создаёт личный чат. Для друга доступно открытие через /api/user/{friendId}/private-chat.
6. Для Accepted доступен DELETE /api/friends/{userId}. Блокировка — PUT /api/friends/{userId}/block; снять её может только владелец через DELETE того же маршрута. После снятия дружба не восстанавливается автоматически.
7. Blocked не допускает новую заявку. Своему аккаунту заявка не предлагается.

Телефон, день рождения, подарки, избранное и общие количества фото/файлов не выдаются UserProfileDto. Их нет в новом окне. Глобальная галерея общих медиа потребовала бы отдельного серверного контракта либо явной клиентской индексации истории; здесь она не имитируется.

## Что исправлено по результатам сверки

- mine/search/members используют страницы по 100 записей до исчерпания, с удалением повторов по ID.
- Перед выбором реакции в канале читается mode/reactionIds; None и Selected ограничивают доступные реакции. Selected собирается в один набор по разрешённым ID, независимо от установленных паков. Снять собственную реакцию можно и при запрете новых.
- Неизвестный historical reactionId разрешается через GET /api/reactions/{id}; файлы загружаются авторизованно и кешируются в памяти.
- Снятие реакции делает DELETE /api/messages/{messageId}/reactions/me и принимает полный серверный snapshot. Чужие counts не обнуляются локально.
- Вложения скачиваются авторизованно и расшифровываются до отображения. Серверный внутренний url не используется как публичная ссылка.
- Прямые сетевые команды перенесены из UI в репозитории/координатор.
